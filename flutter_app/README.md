# 🚀 ECOM SPEED PRO - Flutter Application

تطبيق Flutter متكامل وعصري يحاكي بدقة كافة ميزات، تصاميم، وبوابات موقع **ECOM SPEED PRO** مع لوحة تحكم إدارية متزامنة وشعار ثلاثي الأبعاد فاخر.

---

## 💎 ميزات التطبيق

1. **الهوية البصرية والشعار الرسمي**:
   - الشعار الماسي ثلاثي الأبعاد الرسمي لـ ECOM SPEED PRO مع إضاءات نيون سيان وفوسفورية (`AppLogo`).
   - سمة داكنة ملكية (Royal Obsidian & Cyber Sapphire Theme) مطابقة للموقع بدقة 100%.

2. **الواجهة الرئيسية (Storefront)**:
   - واجهة الهيرو (Hero Section) مع العناوين البارزة والأزرار التفاعلية.
   - مؤشرات وإحصائيات النجاح:
     - 🚀 **رفع نسبة المبيعات 100%**
     - 🌟 **20 متجر تم إطلاقه بنجاح**
     - 🔒 **SSL 256-Bit تشفير بنكي 100%**
   - شريط الميزات والضمانات الأربعة (توصيل وبرمجة 48 ساعة، دعم فني 24/7، بوابات دفع رسمية، ضمان استرجاع 30 يوماً).
   - عرض الباقات الاحترافية الثلاث (صفحة الهبوط 500 د.م، المتجر القياسي 1500 د.م، المنصة المتقدمة 5000 د.م) بنسب 16:9، كبسولات الأسعار، وأزرار "الطلب الآن".

3. **بوابة الدفع الفاخرة (Royal Checkout)**:
   - بطاقة ائتمانية تفاعلية ثلاثية الأبعاد (Interactive Glass Credit Card) تتحدث لحظياً مع إدخال رقم البطاقة واسم حاملها.
   - تبويبات طرق الدفع: البطاقة البنكية، YouCan Pay، وبوابة CMI المغربية.
   - إمكانية إرفاق ورفع صور المنتجات أو الشعار من الهاتف أو المعرض.
   - تأكيد فوري وحفظ الطلب مباشرة في السيرفر مع رسالة واتساب جاهزة لخدمة الكونسيرج (+212 762 357491).

4. **لوحة التحكم الإدارية (Admin Command Center)**:
   - مطابقة للوحة التحكم في المتصفح وتصميم الشاشة المرفقة.
   - 4 بطاقات مؤشرات أداء (KPIs): إجمالي المبيعات، الطلبات المكتملة، قيد المعالجة، ونسبة التحويل.
   - شريط بحث وفلاتر حالة الطلبات (الكل، قيد المعالجة، مكتملة).
   - نافذة تفاصيل الطلب الكاملة مع الاتصال المباشر، مراسلة واتساب، وتغيير حالة الطلب في السيرفر.

## 🛠️ كيفية تشغيل التطبيق

### 1. التشغيل السريع في المتصفح:
انقر مرتين على الملف:
`launch-flutter-app.bat`

أو من سطر الأوامر:
```bash
cd flutter_app
C:\src\flutter\bin\flutter.bat run -d chrome
```

### 2. بناء حزمة أندرويد (APK):
انقر مرتين على الملف:
`build-flutter-apk.bat`

أو من سطر الأوامر:
```bash
cd flutter_app
C:\src\flutter\bin\flutter.bat build apk --release
```

## 📂 هيكلة المشروع

- `lib/main.dart`: نقطة الانطلاق وإعداد الـ RTL وشريط التنقل السفلي.
- `lib/theme/app_theme.dart`: الألوان، التدرجات، والخطوط الملكية.
- `lib/models/`: نماذج البيانات للباقات (`package_model.dart`) والطلبات (`order_model.dart`).
- `lib/services/order_service.dart`: الاتصال بـ API الموقع (`https://ecom-speed-pro.vercel.app/api/orders`).
- `lib/widgets/`:
  - `app_logo.dart`: الشعار الرسمي ثلاثي الأبعاد.
  - `interactive_credit_card.dart`: البطاقة البنكية الزجاجية التفاعلية.
  - `features_ribbon.dart`: شريط الضمانات والمزايا.
  - `hero_stats.dart`: شريط بطاقات الإحصائيات.
- `lib/screens/`:
  - `home_screen.dart`: المتجر الكامل وعرض الباقات.
  - `checkout_screen.dart`: شاشة الدفع ورفع الصور.
  - `admin_dashboard_screen.dart`: لوحة الإدارة ومتابعة المبيعات.
